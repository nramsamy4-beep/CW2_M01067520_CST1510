---

## 🖼️ How to Generate Images

### Option 1: Open HTML Files (Easiest)
1. Double-click `DFD_Diagram.html` or `UML_Diagram.html`
2. The diagram will render in your browser
3. **Save as image:**
   - Right-click → "Save image as..." 
   - OR use Windows Snipping Tool: `Win + Shift + S`
4. Save as PNG and insert into your report

### Option 2: Use Mermaid Live Editor
1. Go to https://mermaid.live
2. Copy content from `.mmd` files
3. Paste into the editor
4. Click "Download PNG" button

### Option 3: Use draw.io (More Control)
1. Go to https://draw.io
2. Create diagrams manually based on the structure
3. Export as PNG/JPG
